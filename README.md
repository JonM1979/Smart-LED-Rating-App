# Smart-LED-Rating-Web-App Demo

Here is the demo to the setup and the web app working all together! The project taught me valuable skills in regards to web app integration and the capabilities it has when in combination with microcontrollers. Getting to experiment with the ESP32 and integrating machine learning into the project was the perfect balance between fun and challenging. Setting up the ESP32 to work with the INA219 wasn't difficult but reworking the code to work with the new sensor and getting the values to show properly on the web app was challenging at first as I didn't have any experience with Java, HTML, or CSS but after reviewing the code and with the help of some ChatGPT, I was able to understand how to modify the code and get it to work in the scope of the project. 

The biggest hurdle that I had to deal with was writing the machine learning aspect of the project. I saw some videos on what it was and how to create a model from TensorFlow and export into TFLite but it took me awhile to understand what I was doing and how to do it. ChatGPT and Microsoft Co-Pilot were great tools to use in explaining the work flow on what to do and how to do it. Another great resource was a video by freeCodeCamp.org that walked through the process of training the model and compressing into a TFLite model: https://www.youtube.com/watch?v=OJnaBhCixng&t=567s Once I trained the model and implemented it into the Arduino code, I had a lot of library-related issues with compiling it; a certain header file couldn't be found and thus a function in the code couldn't work or the ERS value wasn't being properly sent to Firebase and the coding process went back-and-forth like this for awhile. Eventually I got it to work without using a quantizied model. I am still new to using machine learning with edge devices so if there are any errors or methods that I could've used to run the model more efficiently, please let me know! 

After that I just had to implement the rest of the code for the frontend of the web app by adding the code to support the ESP32 sending the ERS value. Once the code was changed in the proper files, the project was done! Again this project was a great foundation in getting an idea in what the workflow is in embedded systems. From the circuit design to the software aspect, this taught me new skills in frontend and backend development, using a microcontroller with WiFi capabilities, integrating it with a web app host through Firebase, and heavily taught me the workflow of developing a machine learning model. I think it even still has room for improvment in the sense of training the model, handling edge cases better, adding concrete anomly detection in the code, and making the web app more professional. I encourage those who are interested in embedded systems and projects like these to take the first step in learning about it, I went in not knowing much about the topics this project cover as it seems daunting at first but with some time and effort, one can really enjoy the process of learning about the capabilities of today's technology and being able to apply it to real world situations. Then special thanks to Random Nerd Tutorials as I used a lot of their work in this project, please check them out as they have many, many projects related to this topic!
